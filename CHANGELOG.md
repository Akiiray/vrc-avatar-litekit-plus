# Changelog

## [0.1.1] - 2026-07-02

### Fixed

- Fix package root structure for the VPM release asset.
- Remove obsolete nested `Packages/` directory from the package layout.
- Remove duplicate asmdef/package root issue.
- Prevent VPM installs from restoring the old package layout by using the manually attached release asset instead of GitHub source archives.

## [0.1.0] - 2026-06-30

### Added

- Initial VPM / UPM package metadata.
- Editor window under `Tools/VRC Avatar LiteKit Plus/Open LiteKit Window`.
- Non-destructive avatar scanner that includes inactive GameObjects and Components.
- Dry Run performance estimate based on public VRChat Performance Rank thresholds.
- Renderer, material, texture, and mobile compatibility diagnostic reports.
- Markdown and JSON report copy actions.
- Placeholder analyzers and planning classes for future safe extension.
- Safety-first documentation and roadmap.
